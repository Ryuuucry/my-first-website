MY LEARNING REFLECTION

From a blank page
to a website.

Creating a personal website helped me understand that a webpage needs both structure and design. HTML gives the content its organization, while CSS shapes the way that content looks through colors, spacing, typography, and layout.

I also learned that publishing a website involves more than writing code. Files need to be organized in the right repository, links need to work, and the finished project needs to be checked on different screen sizes.

One important lesson I take away is that building something takes planning, testing, and patience. Not every part works perfectly on the first try, but each adjustment is a chance to learn.
