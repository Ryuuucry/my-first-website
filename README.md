# Chris — Personal Portfolio

A responsive personal portfolio website for a Grade 12 school activity, built with HTML and CSS.

## File
- `index.html` — complete website, including embedded CSS.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for GitHub Pages to publish the site, then open the published link.

## Submission checklist
- [ ] Check the website on a phone.
